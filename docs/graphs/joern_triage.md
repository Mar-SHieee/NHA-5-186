## Limitations and reproduction

The original spike has 20 samples per language; its Wilson intervals are wide. C/C++ expected-flow estimates use a regex heuristic and manual review is authoritative. The 60 spike samples do not establish representativeness of the full datasets. Any added C scale sample is reported separately and combined with the original only as a clearly labeled extension. The Python wrapper experiment is triage-only; it does not silently alter the raw-path verdict.

python -m scripts.spikes.joern.triage_joern_spike extract
python -m scripts.spikes.joern.triage_joern_spike analyze
python -m scripts.spikes.joern.triage_joern_spike report
