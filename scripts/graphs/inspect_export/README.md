# scripts/graphs/inspect_export/

Each takes an `export.xml` and prints one view of it.

| File / folder | What it is |
| --- | --- |
| `count_types.py` | Node/edge type counts. |
| `list_methods.py` | METHOD nodes. |
| `show_nodes.py` | Nodes. |
| `show_edges.py` | Edges. |
| `dump_line.py` | Everything on one source line. |
